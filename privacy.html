Privacy policy

This policy describes the personal Homebridge Nest integration operated by grimmdav and this public informational website. The integration is for the operator’s household, not a service for the public.

Data accessed and purpose

When authorized, the integration accesses information made available by Google’s Smart Device Management API for the selected home and thermostat. This may include device and room identifiers, names, temperature, humidity, operating mode, target temperature, connectivity, and device-change events. It uses this information to display thermostat status and carry out requested controls in Apple Home.

The integration uses Google Cloud Pub/Sub to receive device updates. It does not request access to Gmail messages, Google Drive documents, or the contents of other unrelated Google services.

Credentials, storage, and logs

The operator configures the OAuth client credentials and refresh token in a Homebridge installation running on a household Raspberry Pi. Configuration, device state, caches, and diagnostic logs may be stored there. Backups may also be kept on the operator’s Mac. These private files are separate from this public website and repository.

Google authorization occurs on Google’s services. This website has no form for passwords or tokens. No claim is made that every Homebridge configuration file, log, or backup is encrypted; those files must be protected by the operator.

Use and sharing

Google user data is used only to provide and maintain the household thermostat integration. It is not sold, used for advertising, used to train machine-learning models, or made public by this website.

Device data and commands are processed by Google’s services and the locally installed Homebridge plugin. Relevant device information is exposed to Apple Home and its configured home members and hubs; processing or synchronization by Apple depends on the household’s Apple Home settings. Google and Apple process data under their own terms and privacy policies. The integration’s use of Google API data is limited to the functionality described here and must comply with the Google API Services User Data Policy, including applicable Limited Use requirements.

Retention and deletion

Local configuration and backups may be retained while needed for operation and recovery. Diagnostic log retention depends on the installed software’s settings; there is no fixed deletion schedule. When the integration is retired, the operator can revoke Google access and remove its configuration, tokens, cached data, and logs. Any retained backups must be handled separately.

Google access can be reviewed or revoked through Google account connections. Revocation stops future authorized access but does not automatically delete existing local data or backups. Apple Home accessories and stored data are managed separately.

This website

The site contains static informational pages. It adds no analytics, tracking scripts, cookies, or data-entry forms. GitHub Pages hosts the site; GitHub states that it logs visitors’ IP addresses for security purposes. See the GitHub privacy statement.

Contact and changes

Contact grimmdav@gmail.com with questions or requests about this integration. Do not include passwords, tokens, or other secrets. Material changes to these practices will be reflected on this page with an updated effective date.
