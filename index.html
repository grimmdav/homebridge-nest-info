Personal household integration

A Nest thermostat,
connected to Apple Home.

Homebridge Nest is a private, personal-use integration operated by grimmdav. It connects the operator’s Nest Learning Thermostat to Apple Home through a locally hosted Homebridge installation and a community Nest SDM plugin.

What the integration does

With the operator’s permission, it uses Google’s Smart Device Management API to read thermostat information, receive device updates through Google Cloud Pub/Sub, and send thermostat commands such as temperature and mode changes initiated through Apple Home.

Why Google access is requested

Nest device access enables thermostat discovery, status readings, and control. Pub/Sub access enables the plugin to receive updates from the configured event subscription. OAuth credentials and tokens are configured privately in Homebridge; this website does not collect them.

For one household

This is not a public service or an invitation to connect other Google accounts. The site provides information for the operator’s OAuth configuration. It offers no sign-in form or thermostat controls.

This project is independent of, and is not endorsed by, Google, Nest, Apple, or the Homebridge project.
