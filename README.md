# Homebridge Nest information

Public informational pages for a personal household Homebridge–Nest thermostat
integration. This repository contains no working integration software, account
credentials, tokens, private configuration, or device backups.

## Pages

- `index.html`: purpose, requested access, and contact information
- `privacy.html`: data practices for the integration and this static website
- `terms.html`: personal-use scope and ownership information
- `style.css`: shared local stylesheet

## GitHub Pages setup

In repository **Settings → Pages**, select **Deploy from a branch**, choose
**main** and **/ (root)**, and save. Use the HTTPS address returned by GitHub.

Expected path after deployment: `https://grimmdav.github.io/homebridge-nest-info/`.
This is not a claim that deployment or Google OAuth acceptance has been verified.

For Google Search Console, use a URL-prefix property matching the deployed site.
Add Google's verification HTML file to this directory exactly as supplied, or add
its verification meta tag to the home page's `<head>`. Never add OAuth secrets.
Search Console verification and Google OAuth branding acceptance are separate
checks; acceptance of the GitHub Pages address remains to be established.
